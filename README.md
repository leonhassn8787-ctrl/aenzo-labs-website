# AENZO LABS Website

Responsive dark-and-gold marketing website for AENZO LABS.

## Deploy on Render
Create a **Static Site** connected to this repository. Set the publish directory to `.` and leave the build command blank. The website entry point is `index.html`.

## Included
- Mobile-friendly landing page
- Service overview and campaign process
- Telegram, X and Binance community links

## Not included yet
This initial static version does not yet include a secure admin dashboard, database, dynamic video/post management, or persistent view counters.
